## Major release
Cello 2.0 redesigns all eight built-in cell-model visual profiles, introduces professional pathway schematics, and adds the Cell Model Library.

The kinetic core is unchanged from v1.8.0. Visual geometry remains explanatory rather than morphometrically validated.
