# Cello v2.0.0 Release Notes

Cello 2.0 is the **Visual Biology & Model Library** release.

### Highlights
- all eight built-in cell models receive updated v2 visual profiles
- modernized membranes, organelles, lighting and model-specific landmarks
- professional pathway maps with live model-flux/status cues
- pathway PNG export
- Cell Model Library with specification export and reproducible presets
- existing Experiment Automation, Microenvironment Engine, Population Mode, Quantitative Analysis, Perturbation Lab and Experiment Workspace retained

### Scientific boundary
Cell visuals are qualitative scientific-communication renderings, not microscopy reconstructions or measured organelle inventories. Pathway schematics describe the represented model graph, not a comprehensive pathway database.
