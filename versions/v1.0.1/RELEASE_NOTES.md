# Cello v1.0.1 — Portable Windows Release

Cello v1.0.1 is the first formally archived public GitHub release of the Cello biochemical cell simulator.

## Highlights

- One user-facing launcher: `Run_Simulator.cello.exe`
- No separate Python installation required
- No terminal window during normal use
- One persistent startup cover
- Main simulator appears after the viewport, worker, and cell state are ready
- Desktop shortcut created after first successful launch
- Cello icon used by the executable and taskbar
- Versioned warm-start cache for later launches
- Complete runtime packaged in `_cello_runtime`
- Responsive layout, dark mode, contrast icons, panel visibility controls, friendly labels, pH readouts, research tools, and scientific audits preserved

## Install

1. Download `Cello_1.0.1_Portable_Windows_x64.zip`.
2. Extract the entire archive.
3. Open the extracted folder.
4. Run `Run_Simulator.cello.exe`.

Keep `_cello_runtime` beside the launcher.

## Scientific boundary

Cello is a transparent research-beta model. It is not a validated digital twin, clinical device, patient-specific predictor, diagnostic system, or source of clinical decisions.
