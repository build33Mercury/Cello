# Cello v2.1.0 Release Notes

Cello 2.1 introduces **Spatial Biology & Cell-Specific Pathways**.

The Pathway Explorer now adds specialized pathway maps only when their relevant cell model is active. Spatial Biology adds deterministic organelle and pathway-anchor inspection with CSV/JSON/PNG export.

The kinetic core remains unchanged from v2.0.0.
