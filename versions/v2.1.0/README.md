## Headline features

- Spatial Biology workspace
- cell-specific pathway selection tied to the active cell model
- hepatocyte ketogenesis/glucose-output/urea-cycle maps
- beta-cell glucose-stimulated insulin-secretion map
- neuron, adipocyte, erythrocyte, skeletal-muscle, and plant-specialized pathway maps

## Scientific boundary

Specialized maps expose processes already represented by Cello; they do not add hidden kinetics. Spatial Biology coordinates are deterministic visualization coordinates, not measured biological localization data.
