# Version archive

This directory stores lightweight release metadata for Cello versions.

Compiled Windows application ZIPs are distributed through GitHub Releases rather than committed to Git history.

## Versions

| Version | Date | Status | Metadata |
|---|---|---|---|
| v1.1.0 | 2026-09-17 | Current release package prepared | [Open](v1.1.0/README.md) |
| v1.0.1 | 2026-08-06 | Previous public release | [Open](v1.0.1/README.md) |

A version folder records release metadata, checksums, and notes. The actual portable Windows ZIP belongs on the corresponding GitHub Release.
