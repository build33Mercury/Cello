# Version archive

This directory stores lightweight metadata for each formally published Cello version.

Compiled application ZIPs are attached to GitHub Releases and are not stored in Git history.

## Versions

| Version | Date | Status | Metadata |
|---|---|---|---|
| v1.0.1 | 2026-08-06 | Current | [Open](v1.0.1/README.md) |

Earlier internal builds were not formally archived as public releases. New version folders should be added only when a real tagged release exists.
