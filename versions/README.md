# Version archive

This directory stores lightweight metadata for formally documented Cello versions.

Compiled Windows builds are distributed through GitHub Releases and are not committed to Git history.

Beginning with the rebuilt release line, the Windows release asset is a single executable named `Cello.exe`.

The v1.1.0–v1.5.0 Windows builds were subsequently rebuilt into the single-file bootstrap architecture after the older multi-file startup route proved unreliable. Each rebuilt executable still requires a native Windows smoke launch before being treated as host-verified.
