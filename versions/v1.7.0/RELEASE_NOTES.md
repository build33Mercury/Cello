# Cello v1.7.0 Release Notes

Cello v1.7.0 introduces the **Microenvironment Engine**.

### New

- extracellular temperature, pH, osmolarity, medium volume, and perfusion controls
- represented extracellular-species concentration, reservoir, and exchange-rate editing
- model-condition presets
- reproducible environment schedules
- exact model-time event boundaries
- medium-replacement events
- live environment and next-event reporting
- Track Stats environment markers
- CSV/JSON schedule export
- experiment/recovery/recording preservation of environment schedules

### Scientific scope

All outputs remain model-generated research-beta results. Presets are not experimentally validated protocols.
