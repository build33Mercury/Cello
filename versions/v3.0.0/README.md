## Major release
Cello 3.0 adds the 119-entry cell-aware Biochemical Pathway Atlas, repairs the Dynamic Pathway Explorer, adds four pathway graph modes, brightens and animates the cell visualization layer, adds DNA-replication visualization, and adds a triggerable mitosis/cytokinesis visual demonstration ending in two daughter cells.

Reference pathways are explicitly labelled schematic and do not imply hidden kinetic equations.
