# Cello v3.0.0 Release Notes

Cello 3.0 is the **Biochemical Atlas, Cell Dynamics & Division** release.

### Headline changes
- Dynamic Pathway Explorer repaired
- cell-aware View Pathways buttons
- 119-entry broad biochemical pathway atlas
- hepatocyte ketogenesis and beta-cell insulin workflows among cell-specific pathways
- DNA replication / S-phase pathway
- flux-history, process-snapshot, state-snapshot and phase-portrait graph modes
- brighter cells and restrained visual organelle mobility
- triggerable S phase through cytokinesis visualization ending as two daughter cells

### Scientific boundary
SIMULATED, STATE-DERIVED and REFERENCE SCHEMATIC coverage are separated in the UI. The division sequence is visual only and does not duplicate the underlying biochemical simulation state.
