# Cello v1.8.0 Release Notes

Cello v1.8.0 introduces **Experiment Automation**.

### New

- parameter sweeps
- microenvironment sweeps
- up to three factors per condition matrix
- deterministic repeated computational runs
- queue preview and run status
- final/mean/minimum/maximum/AUC summaries
- one- and two-factor response plots
- CSV results export
- JSON run-bundle export
- active environment-schedule preservation
- 2,000-run design safety cap

### Interface refinement

v1.8 uses a more conventional desktop-scientific visual system with neutral tool buttons, reduced card rounding, denser tables, standard group boxes, and shorter functional copy.
