## Headline feature

v1.8.0 adds Experiment Automation for model-parameter and microenvironment sweeps, reproducible condition matrices, deterministic run queues, response summaries, response plotting, and CSV/JSON export.

The interface also receives a restrained desktop-scientific refinement.

## Scientific boundary

Automated runs are computational model results. Repeated seeds are not biological replicates, and model sweeps are not empirical dose-response measurements.
