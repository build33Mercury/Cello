# Changelog

## [3.1.0] — 2026-09-20

### Pathway workflow
- added pathway coverage filtering
- added cell-specific-only filtering
- added persistent pinned pathways
- added Ctrl+F search focus
- added graph export to PNG, PDF and SVG
- Pathway Explorer now remains usable when the plotting backend cannot initialize
- added dedicated Pathway Explorer diagnostic handling

### Cell dynamics
- added mitosis pause/resume
- added 0.5×, 1×, 1.5× and 2× playback speeds
- added live division stage/progress display
- limited the visual mitosis demo to the explicitly supported cell-model set
- added ambient-organelle-motion toggle

### Scientific preservation
- `simulation.py`, `regulation.py`, `perturbations.py`, `cell_models.py`, and `pathway_data.py` are unchanged from v3.0.0
