# Scientific scope and limitations

Cello v1.0.1 is technically packaged for end users while its biological model remains a research beta.

## Current boundary

The default parameters are transparent priors rather than a fit to a named:

- Cell line
- Tissue
- Organism
- Patient
- Clinical cohort

## Representation tiers

- **Tier A:** direct equations or explicit state/boundary representations
- **Tier B:** represented pathway or regulatory couplings
- **Tier C:** coarse hypothesis proxies

An entity appearing in the catalog or successfully passing through the software does not establish quantitative biological validity.

## Not intended for

- Clinical decision support
- Diagnosis or treatment selection
- Patient-specific prediction
- Validated digital-twin claims
- Replacement of laboratory experiments
- Medical advice

## Requirements before paper-level use

A serious scientific use case should define the intended biological system and include:

- Calibration to relevant data
- Predefined held-out validation
- Convergence assessment
- Sensitivity analysis
- Uncertainty analysis
- Identifiability analysis
- Alternative-structure comparison
- Independently reproducible experiment bundles

Scientific transparency is a project feature, not a disclaimer to ignore.
