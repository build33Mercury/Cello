# Cello 3.0 Cell-Division Visualization

The v3 cell-division button runs a deterministic visual demonstration:

1. S phase / DNA replication
2. prophase
3. metaphase
4. anaphase
5. telophase
6. cytokinesis
7. two daughter cells

The animation is a scientific-communication visualization rather than a calibrated kinetic cell-cycle simulation. It does not duplicate or branch the biochemical state model.
