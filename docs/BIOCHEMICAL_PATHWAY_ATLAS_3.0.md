# Cello 3.0 Biochemical Pathway Atlas

The v3 atlas contains 119 curated pathway definitions covering major carbohydrate, central-carbon, mitochondrial, lipid, amino-acid, one-carbon/nucleotide, cofactor/redox, gene-expression/proteostasis, DNA-maintenance/cell-cycle, signaling, plant and cell-specialized pathway families.

Coverage labels are part of the scientific contract:

- **SIMULATED**: uses kinetic model outputs.
- **STATE-DERIVED**: summarizes represented model state.
- **REFERENCE SCHEMATIC**: biochemical context only; no hidden kinetic implementation is implied.

Available pathways and shortcut buttons are filtered by the active built-in cell model.
