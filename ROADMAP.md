# Roadmap

This roadmap describes intended engineering directions, not promises of validated biological performance.

## v1.1 — Documentation and release hardening

- Public screenshots and demonstration media
- Cleaner in-application version information
- Expanded troubleshooting documentation
- Automated release metadata validation
- Consolidated third-party license inventory
- Reproducible build documentation

## v1.2 — Developer-facing structure

- Publish stable model/entity schemas
- Document simulation inputs and outputs
- Add importable experiment configurations
- Expand save/export formats
- Add example biochemical intervention scenarios

## v2.0 — Architecture expansion

- Stronger separation of model, state, simulation, and rendering layers
- Plugin-style biological modules
- Explicit parameter provenance and evidence tiers
- Validation, sensitivity, and uncertainty workflows
- Reproducible experiment bundles

Roadmap items can change as testing reveals technical or scientific constraints.
